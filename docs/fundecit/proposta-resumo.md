## Plataforma Digital (INKU·AI)
A plataforma web é o produto principal do projecto. Componentes:
1. Sistema de autenticação e gestão de utilizadores (JWT, RBAC)
2. Módulo de startups e equipas (multi-tenant)
3. Módulo de projectos IA (CRUD, GitHub integration)
4. Sandbox seguro de execução de código (Docker, Python)
5. Módulo de métricas IA (accuracy, loss, F1-score)
6. Sistema de mentoria académica
7. Painel de administração FUNDECIT

## Stack Tecnológico
- Backend: Node.js + Express.js + JWT
- Frontend: HTML5 + Bootstrap 5 + JavaScript
- BD: PostgreSQL (Supabase) + MongoDB (Atlas)
- Infra: Render + Docker + GitHub Actions
